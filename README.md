# Top 5 Tamil Films

A simple static HTML page showcasing five of the greatest Tamil films of all time, featuring posters, introductions, story summaries, and what makes each film special.

## 🎬 Overview

This project is a single-page website (`index.html`) built with plain HTML to highlight iconic Tamil cinema. Each film entry includes:

- Movie poster
- Introduction
- Story summary
- Why it's special
- Conclusion

## 📽️ Films Featured

1. **Nayakan** (1987) – Directed by Mani Ratnam, starring Kamal Haasan
2. **Baashha** (1995) – Directed by Suresh Krissna, starring Rajinikanth
3. **Thalapathi** (1991) – Directed by Mani Ratnam, starring Rajinikanth & Mammootty
4. **Vikram** (2022) – Directed by Lokesh Kanagaraj, starring Kamal Haasan, Vijay Sethupathi & Fahadh Faasil
5. **Jai Bhim** (2021) – Directed by T. J. Gnanavel, starring Suriya
